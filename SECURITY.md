# Security Policy

## Supported Versions

Currently, only the latest version of TeleMaster Pro receives standard security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a priority. If you discover any security-related issues (e.g., XSS, insecure dependencies, layout bypass), please DO NOT report them via public GitHub issues. 

Instead, please email the author/seller directly at the email provided on the sales page or support portal. We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress.

### What to include in your report:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact on the application or its users.
- (Optional) Suggested patches or mitigations.

Thank you for helping keep this project secure!
