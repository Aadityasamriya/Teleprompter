# Contributing to TeleMaster Pro

First, thank you for purchasing TeleMaster Pro and considering contributing to its ecosystem!

Since this is a commercially licensed product, standard open-source Pull Requests to the main repository might not be applicable directly. However, if you've discovered a bug or created an amazing feature you'd like to share with the community, here is how you can help:

## Got a Question or Problem?

Before opening an issue, please consult:
1. The **README.md** file for deployment and configuration details.
2. Ensure you have properly updated `src/config.ts`.

If you still need help, open an issue using the provided templates or reach out directly via the support email.

## Found a Bug?

If you find a bug in the source code, you can help us by [submitting an issue](#). Even better, you can submit a Pull Request with a fix if you have access to the private repository.

**When reporting a bug, please include:**
- A detailed description of the bug.
- Steps to reproduce.
- Expected behavior vs actual behavior.
- Your environment (Browser, OS, Node version).

## Feature Requests

We love feature requests! If you have a brilliant idea for a new feature, please submit an issue explaining the feature, the use case, and how it would benefit creators using the platform.

## Code Standards
- **TypeScript:** Strict type checking is enabled. Ensure all new code is properly typed.
- **Tailwind CSS:** Use Tailwind utility classes directly. Avoid creating custom CSS classes unless absolutely necessary.
- **React:** Use modern functional components with hooks.
