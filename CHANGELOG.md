# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-11

### Added
- Initial Release of **TeleMaster Pro**.
- Minimalistic Editor UI with word count, character count, and time estimation.
- High-performance Auto-Scroller with dynamic WPM calculation.
- Teleprompter Mirroring support for physical teleprompter glass.
- Live Focus Tracking Line for script reading.
- Integrated Affiliate marketing component for passive monetization.
- Centralized `config.ts` for zero-code white-labeling and rebranding.
- Responsive mobile & tablet layout.
